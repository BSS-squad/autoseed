# Единое автоматическое подключение AutoSeed

## Цель

Действующий Pages-интерфейс выражает одно намерение игрока: подключиться к
рассеиваемому серверу. Конкретную цель определяет только существующая политика
AutoSeed `Mix → Spec Ops → Invasion`; карточки серверов служат для наблюдения.

## Решение

- Удалить прямые кнопки и обработчик входа на выбранный пользователем сервер.
- Переименовать «Выбор сервера» в «Состояние серверов», а маркер «выбран» — в
  «цель AutoSeed». Переключение карточки меняет только показанный состав.
- Основная кнопка в выключенном состоянии говорит `Подключиться`, во включённом
  — `Отключить`.
- На первом запуске кнопка синхронно передаёт безопасный
  `steam://open/main`, затем показывает отдельное подтверждение
  `Steam открылся — подключиться`. Только подтверждение синхронно открывает
  служебное окно, сохраняет готовность и включает AutoSeed.
- До подтверждения Steam запрос `join-link` запрещён. Старые эвристики
  `blur`/`hidden` и URI `steam://run/393380` удаляются.
- После однажды подтверждённой готовности обычное нажатие сразу открывает
  служебное окно и включает AutoSeed. Закрытие окна продолжает обрабатываться
  существующим восстановлением.

## Сохранённые свойства

- строгий приоритет, лимит 80 и пропуск неподходящих серверов;
- on-demand получение ссылки без хранения в snapshot;
- смена цели, cooldown, периодическое переподключение и тестовая
  последовательность;
- информационные составы, слабая сторона и часы игроков;
- мобильный режим наблюдения без ложного Steam-входа.

## Отказы

- Steam не удалось вызвать: готовность не сохраняется, AutoSeed выключен;
- popup заблокирован на подтверждении: готовность не сохраняется, ссылка не
  запрашивается;
- карточка сервера нажата: меняется только подробная карточка, число запросов
  `join-link` остаётся прежним;
- сохранённая готовность есть, но popup заблокирован: AutoSeed не включается.

## Не входит в задачу

- перенос Pages на новый backend;
- изменение exporter или политики выбора;
- переработка журнала, топов, розыгрышей и других разделов.
