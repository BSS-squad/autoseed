# Система интерфейса

> Исторический документ прежнего React-приложения. Его компоненты и правила
> больше не образуют опубликованный интерфейс Pages; подробности сохранены в
> истории Git.

Текущая страница — один доступный документ перехода. Для неё обязательны:

- понятный заголовок о переезде и обычная ссылка на основной AutoSeed;
- работоспособность без JavaScript;
- видимый клавиатурный фокус и область ссылки не ниже 48 пикселей;
- отсутствие горизонтального переполнения на 320/390/768/1440 пикселях;
- достаточный контраст текста и состояний ссылки;
- отсутствие внешних ресурсов и пользовательских данных.

Поведение и команды проверки описаны в [README](../README.md).
