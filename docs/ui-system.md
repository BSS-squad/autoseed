# Система интерфейса

## Назначение

Публичные разделы должны выглядеть как один сайт и собираться из общих
компонентов. Этот документ фиксирует минимальный набор правил, который нельзя
дублировать внутри отдельного маршрута.

## Каркас

- `PageShell` задаёт ширину, фирменный фон и навигацию.
- `PageHeader` задаёт порядок надзаголовка, названия, пояснения и дополнительных
  показателей.
- Каждый публичный раздел находится в отдельном компоненте каталога
  `src/pages`.
- `App` хранит состояние автоподключения, выбирает маршрут и собирает главный
  экран; код остальных страниц в нём не размещается.

## Общие элементы

- `MetricCard` — один показатель с подписью и необязательным пояснением.
- `Notice` — статус или ошибка с одним из четырёх смысловых состояний.
- `EmptyState` — отсутствие данных без отдельной разметки для каждого раздела.
- `SegmentedControl` — группа взаимоисключающих вариантов.
- `ServerSelector` — область выбора сервера.
- `ResponsiveTable` — доступная с клавиатуры область широкой таблицы с явной
  внутренней прокруткой.

Компоненты находятся в `src/components/Primitives.tsx`. Специальный класс
раздела допускается только для композиции или действительно уникального вида.

## Переменные

Базовые цвета, тени, радиусы, интервалы, высота элементов управления, скорость
переходов и максимальная ширина задаются только в `:root` файла
`src/styles.css`.

Контрольные ширины:

- 1240 px — переход сложных сеток к сокращённому числу столбцов;
- 860 px — одноколоночная композиция;
- 640 px — телефонная навигация и компактные элементы;
- 420 px — узкий телефон;
- 360 px — минимальная ширина приёмки.

## Журнал матчей

- «Итоги матча» и «События матча» — два разных уровня навигации. Итоги
  показывают финальную таблицу Squad, события — записи действий по ходу игры.
- Ссылки сохраняют выбор сервера, матча и категории событий в параметрах
  `#journal`; переименование видимых элементов не меняет этот договор.
- Итоговая таблица показывает по 10 игроков каждой стороны и предлагает
  постраничный вывод. При горизонтальной прокрутке имя игрока закреплено.
- На телефоне горизонтальные области сопровождаются явной подсказкой, а
  категории событий выводятся без скрытых за краем кнопок.
- Защищённая выгрузка MDC остаётся отдельным действием и не смешивается с
  публичной итоговой таблицей.

## Ачивки

- Короткое пояснение при наведении допустимо только на широком экране.
- Нажатие или клавиатурная активация значка открывает нативное диалоговое окно
  верхнего слоя с названием, изображением, описанием и причиной выдачи.
- На телефоне окно закрепляется внутри видимой области, длинный текст
  прокручивается внутри него, а закрытие доступно кнопкой, `Escape` и нажатием
  на фон.
- Нельзя позиционировать полное пояснение относительно значка: крайние значки
  в строках и карточках неизбежно выводят такую подсказку за границу экрана.

## Проверка

- пять маршрутов при 1440×1000, 390×844 и 360×800;
- мышь, касание, `Tab`, `Enter` и пробел;
- отсутствие общей горизонтальной прокрутки;
- `npm run test:unit`, `npm run test:e2e`, `npm run build`;
- `git diff --check`.
