# Развёртывание

> Исторический документ прежнего приложения. Настройки exporter-ов,
> `AUTOSEED_RUNTIME_CONFIG_JSON`, клиентской логики и отдельного интерфейса Pages
> больше не применяются. Подробности доступны в истории Git.

## Актуальная схема

GitHub Pages публикует статический `index.html`, который переводит посетителя на
единый сайт `https://squad.leo-land.ru`. Четыре совместимых фрагмента URL
сохраняются, остальные входы ведут на `/autoseed`. Источники данных и секреты
Pages не использует.

Для выпуска достаточно:

1. В `Settings → Pages` выбрать GitHub Actions.
2. Задать переменную репозитория `VITE_BASE_PATH=/autoseed/`.
3. Принять изменение в `main` и дождаться сценария `Deploy Pages`.

Сценарий проверяет качество, публикует `index.html` и `release.json`, сверяет
точную ревизию, готовность единого сайта и поведение боевого перенаправления.
Секрет `AUTOSEED_RUNTIME_CONFIG_JSON` больше не нужен и может быть удалён из
настроек репозитория.

Команды локальной и боевой проверки приведены в [README](../README.md).
